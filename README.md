# Common Good - Direct Democracy Platform

Blockchain-powered participatory governance replacing bureaucratic inefficiency with transparent, citizen-controlled resource allocation.

## Quick Start
```bash
docker-compose up
npm run dev
```

## Architecture
- **Smart Contracts**: Stellar Soroban (Rust)
- **Backend**: Node.js + Express + TypeScript
- **AI Agent**: Python + FastAPI + TensorFlow
- **Frontend**: React + TypeScript + Tailwind
- **Database**: Supabase (PostgreSQL)
- **Blockchain**: Stellar Testnet → Mainnet
